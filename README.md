# 우리 회사 연차관리 - 사내 모바일 전용 연차 관리 시스템 배포 가이드

본 패키지는 4인 규모의 우리 회사에서 실제로 즉시 운영할 수 있도록 제작된 사내 전용 연차 관리 시스템(Node.js + Express + SQLite + HTML5 PWA) 풀스택 소스코드입니다.

---

## 1. 주요 기능 및 업무 규칙 구현 현황

1. **정규 근무시간 및 연차 최소 단위**:
   - 정규 근무: 08:30 ~ 17:30 (점심시간 12:30~13:30 제외, 실근무 8시간)
   - 최소 단위: 2시간 단위 (0.25일)
   - 4개 시간 구간:
     1. 08:30~10:30 (2h, 0.25일)
     2. 10:30~12:30 (2h, 0.25일)
     3. 13:30~15:30 (2h, 0.25일)
     4. 15:30~17:30 (2h, 0.25일)
   - 같은 날 여러 구간 동시 선택 지원 (예: 1+2구간 = 4h / 0.5일 반차)
   - 종일 및 2일, 3일, 5일 이상 연속 연차 지원 (주말·공휴일·회사지정휴무일 자동 제외)
   - 내부 시간(hours) 단위 저장, 일수와 시간 동시 표기 (`9.25일 (74시간)`)

2. **회사 연차 발생 규칙 (매년 1월 1일 일괄 부여)**:
   - 입사 첫해: 1개월 개근 시 1일 발생 (관리자 확인/입력)
   - 입사 다음 해: 1월 1일 15일 일괄 부여
   - 근속 연차: 2년마다 1일 추가 (최대 25일)
   - **2026년 기준 검증**:
     - **고수현** (2023.07.01 입사): 2024년 15일 -> 2025년 15일 -> **2026년 16일**
     - **김남흥** (2021.08.16 입사): 2022년 15일 -> 2023년 15일 -> 2024년 16일 -> 2025년 16일 -> **2026년 17일**

3. **2단계 결재 프로세스**:
   - 일반 직원: 신청 -> 김남흥 차장 1차 승인 -> 대표님 최종 승인 -> 연차 확정
   - 김남흥 차장 본인 연차: 신청 -> 대표님 최종 승인 직행 (1차 승인 스킵)
   - 대표님 본인 휴가: 대표 직접 일정 등록
   - 최종 승인 시에만 연차 잔여량 차감 및 공유 달력 반영
   - 반려 사유 입력 필수 및 처리 이력 자동 기록

4. **직원 공유 달력**:
   - 최종 승인된 일정만 전 직원에게 표시
   - 개인별 잔여량 및 연차 사유는 비공개 보호

5. **보안 및 데이터 관리**:
   - bcrypt 단방향 비밀번호 해싱
   - JWT 세션 토큰 및 권한 기반 미들웨어 (Role-Based Access Control)
   - 관리자 연차 수동 조정 시 전/후 수치 및 사유 감사 로그 보관
   - 엑셀 호환 CSV (UTF-8 BOM) 다운로드 및 전체 백업 지원

## 2. 서버 실행 방법 (사내 PC, 사내 NAS, 또는 클라우드 서버)

### 방법 A: 로컬 Node.js 직접 실행
```bash
# 1. 패키지 의존성 설치
npm install

# 2. 서버 실행 (포트 3000 기본)
node server.js
```
브라우저에서 `http://localhost:3000` 또는 `http://[서버IP]:3000` 으로 접속합니다.

### 방법 B: Docker 컨테이너 실행
```bash
# Docker 이미지 빌드 및 실행
docker build -t annual-leave-app .
docker run -d -p 3000:3000 -v $(pwd)/data:/app/data --name annual-leave annual-leave-app
```

## 3. 스마트폰 홈 화면 추가 (PWA 앱처럼 사용)

1. 사내 Wi-Fi 또는 외부 도메인(HTTPS)으로 접속합니다.
2. **iPhone (Safari)**:
   - 하단 공유 버튼(네모 위 화살표) 터치 -> **"홈 화면에 추가"** 선택
3. **Android (Chrome)**:
   - 우측 상단 더보기(⋮) -> **"앱 설치"** 또는 **"홈 화면에 추가"** 선택
4. 스마트폰 바탕화면에 "우리 회사 연차관리" 아이콘이 생성되어 독립 앱처럼 구동됩니다.
